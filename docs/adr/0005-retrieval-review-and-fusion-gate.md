# ADR 0005：保留可复现基线，融合实验通过评测后再启用

- 状态：已接受。
- 日期：2026-10-17。

## 背景

V1.3 在同一 Flask 开发集上改善宏平均，但仍有三道题 Recall@10 回退。直接堆叠子查询会让候选数量和重复证据共同改变排名，需要以逐题证据、固定预算和可重放实验判断收益。

## 决策

- 保存 V1.2、V1.3 的原始结果和数据集，实验不得覆盖它们或调整真值来提升指标。
- 使用单独的 `experiments/retrieval_review.py`，校验输入 hash、snapshot、索引集合，并逐题复现冻结分数。
- 标识符子查询最多三条，每路 100 个候选；RRF 的 k 固定为 60，去重后融合。查询只能依赖用户问题，不能读取 gold/预期答案来扩词。
- 开发集门槛为 Recall@10 提高、四项宏平均均不下降、没有新增零命中题。当前实验未通过，因此不进入默认检索。
- 这 30 道题已参与权重选择，后续新增独立验证集；不将当前结果宣传为独立测试或跨仓库泛化结论。
- 本阶段修复 `search` 的策略标识，使 CLI 与 `evaluate` 报告一致；保留默认排序规则。

## 影响

保留了可审计的负实验，避免将“更多查询”误认为“更好的召回”。独立验证后再讨论调整默认检索或接入语义拆解。模型生成和 API key 配置仍在 V2 单独处理。
