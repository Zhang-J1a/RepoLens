# ADR 0006：V1 交付范围与冻结验证

- 状态：已接受。
- 包版本：1.0.0。
- 用户授权：直接完成 V1，按已有产品规格一次收尾。

## 决策

V1 交付本地 commit 索引、Python/Markdown 证据检索、离线评测、安装包及可运行演示。生成回答、引用生成校验与 provider 接入属于 V2；不以这些未来功能阻塞 V1 收尾。

保留已测的词法权重，统一候选池为 100，修复同名符号范围校验和损坏证据边界。冻结 20 道新题后再运行，以新验证结果描述能力，禁止看到失败后改标注或继续调参。纯中文检索无命中的限制如实写入 README。

构建 wheel 并在干净环境离线安装，使用 `python -I` 验证确实加载安装包。CI 配置覆盖 Windows/Ubuntu、Python 3.12/3.13；未执行的远程任务不宣称已通过。

## 影响

V1 已形成可安装、可演示、可复现的检索基础，尚不是完整的生成式 RAG。后续优先完成 V2 的可替换 provider、证据预算和带验证的回答链路；DeepSeek API key 在实际模型请求前配置。
